⚙️ Como Funciona o Sistema

☁️ Armazenamento Cloud

Todo o código submetido é versionado e armazenado de forma segura no Amazon S3, garantindo integridade e persistência dos dados para o torneio.

🤖 Orquestração Python

Um orquestrador central gerencia as partidas em paralelo, utilizando multiprocessamento para simular mesas simultâneas com alto desempenho.

Fluxo do Torneio

O torneio é dividido em fases eliminatórias. Após cada fase, o sistema realiza o Clean-up de arquivos temporários e gera um ranking dinâmico baseado no saldo final de fichas de cada mesa.
